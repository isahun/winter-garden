# Secret Garden — Wireframes de referència

> Wireframes low-fidelity per usar com a guia a Figma.
> Ordre: de més a menys prioritat per al MVP.
> Nota: els icones ASCII substitueixen emojis per compatibilitat amb Obsidian.
>   [G] = logo Secret Garden  [c] = carret  [=] = menu hamburger
>   [@] = pin mapa  [*] = estrella  [x] = eliminar  [e] = editar
